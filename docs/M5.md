## Catalog and hostname rules

- Search and alternatives keep only Shopify-store items with an HTTPS checkout link. The catalog also lists external merchants (`source: "external"`, no `checkout_url`), which the giver could never buy here. `eligible.native_checkout` is false for every item under the unsigned demo profile, so it is not used as the filter.
- `proxy.ts` sends page visits on any other production hostname (deployment-specific Vercel URLs) to `APP_URL` with a 308 redirect. Origin checks only accept `APP_URL`, so creating a gift from another hostname previously failed with "Invalid origin". API routes still enforce the check and now return JSON errors.
- Demo gift reseeded on 2026-11-16 after the filter; all alternatives are Shopify stores.
